Recording

Quality and target for clips captured by Sparta Clips. Hardware H.264 (Windows Graphics Capture) keeps the overhead low.

Quality presetLow is light on disk and CPU; High is sharpest. Pick Custom to set framerate, bitrate and resolution yourself.
FramerateFrames per second in the recording. 120 needs a 120 Hz+ display, a game running that fast and a capable GPU encoder (pair it with a higher bitrate).
EncoderH.264 plays everywhere · AV1 makes the smallest files (hardware needs RTX 40 / Arc / RX 7000) · H.265 is small too. ⓘ
In-app HEVC preview
BitrateHigher looks better but uses more disk. 20 Mbps is a good 1080p balance.
ResolutionSource records at the captured size; otherwise it's scaled to the chosen height.
Capture modeWhole display records the screen the game is on; Game window records only the foreground game (no desktop, no overlays).
Estimated sizeApproximate disk use at these settings (real size varies with on-screen motion).

Dual screen

Record two monitors into one clip with a layout you arrange — side‑by‑side, stacked, or picture‑in‑picture (a small screen inside the other, like a streamer's webcam). Locked to H.264 · 60 fps · ~1080p per screen for maximum compatibility; every monitor keeps its true shape — ultrawide included.

Dual-screen captureComposite two displays into a single recording. Applies to instant replay and manual recordings, and overrides the encoder / framerate / resolution above.

Instant replay

Always-on background buffer — never miss a moment. While a game runs the recorder keeps the recent past; press Ctrl+Alt+F10 to save just the last few seconds as a clip.

Enable instant replayArm the background buffer automatically when you launch a game. Takes precedence over full auto-record.
Auto-highlight · League / TFTAuto-saves a replay on your kills & assists using Riot's official in-game API — no memory access, anti-cheat-safe. Needs Instant replay on; off by default.
Replay length · 30sHow many seconds back the Save replay hotkey captures — anywhere from 10s to 2 minutes.
Replay clip sizeRoughly this much per saved replay at the current length & quality.

Folder & hotkey

Per-game profiles

Override capture quality for specific games. When a recording's game name contains a profile's match text, that profile's settings apply instead of the defaults above. Affects full recordings (the instant-replay buffer always uses the defaults).

General

App startup and window behaviour.

Instant-replay policyAlways armed keeps the background buffer rolling whenever Sparta Clips runs. Only in a game arms it when a game is detected in the foreground.
Start with WindowsLaunch Sparta Clips to the tray on sign-in so instant replay is ready.
Start elevated (anti-cheat games)Keeps the hotkeys working in games with anti-cheat. Windows asks for approval once. ⓘ
Keep running when closedOn the window's X, keep Sparta Clips in the tray (capture & instant replay stay alive). Turn off to quit fully on close.
In-game recording indicatorShow a small ● REC timer over the game while a full recording runs, so you always know capture is live.
DiagnosticsOpen the folder with Sparta Clips' logs — handy when reporting a bug.
